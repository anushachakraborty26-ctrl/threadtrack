## What each source contributes

- **McKinsey** — global apparel context: tariffs, sourcing mix, executive intent on pricing/sourcing levers
- **Inc42** — Indian D2C ecosystem: market sizing, Tier mix, delivery SLA evolution, Fashion & Apparel positioning
- **TexMin** — Indian manufacturing & exports: cluster geography, fabric category mix, state/district concentrations
- **Wazir** — fabric-level Indian export composition (cotton woven dominance, knit growth)
- **Unicommerce** — Festive-season RTO dynamics, COD vs prepaid split, category growth
- **GrowwwTech** — Category-by-category RTO benchmarks, CAC by channel, retention/CLV
- **Outlook Business + Business Standard + Inc42 + Silicon India** — Snitch-specific operational and financial data
- **Sourcing Journal + Business Standard** — Tirupur cluster current state (capacity utilization, export volumes)
- **YourStory + BePragma** — D2C return rate and RTO root causes

## How these inform ThreadTrack

The synthetic purchase-order dataset generated in Phase 2 uses distributions calibrated to numbers extracted from these sources. Each cited benchmark in `docs/benchmarks.md` references one of the sources above with a specific reference point (page, section, or URL).
